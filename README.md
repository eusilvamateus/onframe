# OnFrame

OnFrame e uma extensao local para Chrome e Edge que ajuda vendedores do Mercado
Livre a gerenciar anuncios diretamente pela pagina publica do produto.

## Recursos

- Fotos: adicionar, remover, reordenar e avaliar a qualidade das imagens.
- Descricao e caracteristicas: editar informacoes do anuncio no proprio contexto
  em que o comprador as consulta.
- Preco e promocoes: revisar custos, oportunidades e participacoes disponiveis.
- Variacoes: aplicar alteracoes em massa quando o anuncio permitir.
