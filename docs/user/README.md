# Guias do OnFrame

Esta pasta reune materiais para quem usa o OnFrame no dia a dia. Os guias
explicam como instalar a extensao, conectar uma conta e operar os recursos na
pagina do anuncio.

  pagina do anuncio.
- [Instalacao e atualizacao](instalacao-e-atualizacao.md) - instalacao,
  inicializacao, diagnostico, atualizacao e remocao.
- [Editar descricao no anuncio](editar-descricao.md) - como alterar o texto sem

- [Editar caracteristicas do produto](editar-caracteristicas.md) - como revisar

- [Promocoes e acoes em massa](promocoes-acoes-em-massa.md) - como revisar,
  aplicar, alterar ou remover promocoes, inclusive em variacoes.
